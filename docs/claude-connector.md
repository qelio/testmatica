# Подключение Claude к ТестМатике

Claude (Claude Desktop или claude.ai) может сам создавать задачи в вашем банке и теорию в библиотеке — от вашего имени,
как ваши личные материалы. В публичный банк и библиотеку они попадают как обычно — через модерацию (решение №41).

## Подключить (один раз)

1. ТестМатика → **Личный кабинет → Подключение Claude** → «Выпустить ключ». Скопируйте **адрес подключения** вида
   `https://testmatica.ru/api/mcp/tm_…` — ключ в его конце показывается один раз.
2. Claude (приложение или claude.ai) → **Settings → Connectors → Add custom connector** (у организаций коннектор сначала
   добавляет владелец в Organization settings → Connectors).
   - Название: `ТестМатика`
   - Адрес: скопированный адрес с ключом. Поля OAuth оставьте пустыми.
   - У «своего коннектора» Claude нет поля для заголовков, поэтому ключ — в адресе. Клиенты, которые умеют передавать
     заголовки, могут подключаться к `https://testmatica.ru/api/mcp` с `Authorization: Bearer tm_…`.
3. Готово. Ключ можно отозвать в личном кабинете — Claude сразу потеряет доступ.

## Что умеет Claude

| Функция | Что делает |
|---|---|
| `upload_image` | Загрузить картинку из файла (base64: PNG, JPEG, GIF, WebP до 20 МБ) — вернёт Markdown для вставки в текст, задачу или тест |
| `list_subjects`, `list_topics`, `list_exam_items` | Предметы, рубрикатор банка (разделы и темы), задания ЕГЭ/ОГЭ — чтобы правильно разложить задачи |
| `search_tasks`, `get_task` | Найти задачи (мои или публичный банк, по тексту или номеру «(100345)») и открыть целиком |
| `create_task`, `update_task` | Создать задачу любого типа (выбор, короткий ответ, развёрнутый, код) или исправить свою |
| `list_my_courses`, `get_course` | Мои курсы библиотеки и их структура |
| `create_course`, `add_section`, `add_module` | Курс → раздел → модуль |
| `set_course_theme` | Оформление курса для учеников: «Классика» или игровое «Комикс» (его можно задать и сразу в `create_course`) |
| `add_material`, `update_material` | Текст урока, карточка теории или задача из банка в модуле; правка текста |
| `search_library_courses` | Опубликованные курсы публичной библиотеки — к их модулям можно привязать свой тест |
| `list_my_tests`, `list_module_tests`, `get_test` | Мои тесты; тесты модуля курса (общие «для всех» и мои личные); тест целиком |
| `create_test`, `update_test` | Тест из задач банка (по номерам), по желанию привязанный к модулю курса; `shared` — «для всех, кто проходит курс» (только автор курса). Назначает тест педагог в интерфейсе |

Формулы — LaTeX (`$…$`, `$$…$$`). Картинки по ссылкам из интернета и вшитые в текст (`![…](data:image/png;base64,…)`,
как в HTML-файлах уроков) переносятся в хранилище платформы сами; картинку из прикреплённого файла Claude загружает
через `upload_image`.

## Примеры просьб

- «Посмотри рубрикатор по алгебре и создай 10 задач на квадратные уравнения: 4 базовые, 4 средние, 2 сложные, с разбором. Короткий ответ.»
- «Сделай курс „Линейные уравнения, 7 класс“: два модуля, в каждом карточка теории и по 3 задачи из моего банка.»
- «В задаче (100345) ответ должен быть 3,5 — исправь.»
- «К модулю „Миссия 1“ курса „Вебоград“ сделай практическую работу для всех из 5 задач и отдельно контрольную только для меня.»
- «Найди в моём банке задачи без темы и разложи их по рубрикатору.» (пока — по одной, через `update_task`)

## Как устроено

Сервис `mcp` (`services/mcp`) принимает запросы Claude по протоколу MCP (Streamable HTTP). Ключ из адреса (`/api/mcp/tm_…`,
в журнале сервиса маскируется) или из заголовка обменивается
в identity на обычный токен пользователя, дальше — публичные API assessment, content и media: права и проверки те же,
что в интерфейсе. Своей базы у сервиса нет; ключи хранятся в identity только в виде хеша.
