# Решения по противоречиям ТЗ (v1.2)

Согласовано 2026-09-23.

1. **Сроки оплаты.** Дедлайн оплаты — за 2 ч до начала. Если не оплачено — одно уведомление педагогу («ждать / отменить без штрафа»). Оплатить можно до старта; при старте без оплаты — автоотмена. Напоминание за 1 ч убрано.
2. **Комиссия.** 10% (индивидуальные и групповые), 0% (пробные, бесплатные/школьные). Значение — настройка в админке.
3. **Способы оплаты.** СБП, SberPay, банковская карта (ЮKassa).
4. **Записи.** Бесплатный тариф: 14 дней, не более 3 записей (4-я вытесняет старейшую). Базовый: 30 дней, без лимита по количеству. Определяется тарифом педагога.
5. **Лимит видео 40 мин.** Только для бесплатных/школьных занятий на бесплатном тарифе. Платные занятия через платформу — без лимита. Предупреждение за 5 мин.
6. **2FA.** Обязательна для всех, кроме учеников, созданных вручную без email/телефона; при первом входе им предлагается привязать контакт, после чего 2FA включается. Для педагогов, модераторов и админов — без исключений.
7. **Повторная сдача тестов.** «Активен» = можно открыть и смотреть задания/результаты. Отправка — один раз. Новая попытка только при переназначении; все попытки хранятся.
8. **Языки программирования.** v1 — только Python. Песочница (Docker) и модель задачи мультиязычные; настройка в админке с одним вариантом.
9. **Удаление аккаунта.** ПДн удаляются/обезличиваются; финансовые транзакции хранятся обезличенно в срок по закону; отзывы и материалы — от «Удалённого пользователя». 30 дней на восстановление.
10. **Публичный профиль.** В поиске только при включённом режиме «Репетитор» и заполненном профиле. Школьный учитель в поиске не виден. Верификация не нужна для профиля, но нужна для приёма оплаты (метка/фильтр в поиске).
11. **Автовывод.** Срабатывает, только если баланс ≥ 5 000 ₽; иначе переносится на следующий цикл.
12. **Личные чаты.** Только при наличии связи: привязанный педагог/ученик, одногруппник, репетитор, откликнувшийся на заявку. Новому репетитору — только через «Хочу с вами заниматься» (чат переговоров). Фильтр контактов — позже.
13. **Недостающие правила.**
    - Открытая заявка автоматически закрывается через 14 дней; ученик может закрыть её сам.
    - Перенос оплаченного занятия: оплата переходит на новое время; несогласие ученика с переносом от педагога = отмена педагогом (полный возврат).
    - Чеки самозанятых: интеграция с «Мой налог» (API ФНС); запасной вариант для v1 — ручная загрузка чека педагогом.
    - Цена подписки и провайдеры — решение бизнеса, в коде это настройки.
