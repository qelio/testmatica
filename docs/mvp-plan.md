# План MVP — образовательная платформа

Основа: ТЗ v1.2 + [decisions.md](decisions.md).

## Принципы

- **Порядок от простого к рискованному.** Школьный режим бесплатный, без денег и юридических требований — его можно запустить первым и получить реальных пользователей. Маркетплейс требует платежей, escrow, 115-ФЗ и модерации — это самый тяжёлый блок, он идёт позже.
- **Микросервисы с брокером сообщений (RabbitMQ).** Сервисы общаются синхронно по REST и асинхронно через события в брокере.
- **Docker с первого дня.** Локально всё запускается через docker-compose, в облако переезжают те же образы.
- **Каждый этап заканчивается рабочим продуктом**, который можно показать пользователям.

## Этап 0. Фундамент

- Репозиторий, CI/CD, окружения dev/stage/prod, хостинг в РФ
- Бэкенд-каркас, фронтенд-каркас, БД (PostgreSQL), Redis, очередь задач, S3-хранилище
- Регистрация по email, вход, 2FA (email/телефон), сброс пароля
- Роли: ученик, педагог, модератор, администратор; матрица прав
- Аудит-лог (неизменяемый)
- Согласие на обработку ПДн, rate limiting, защита от брутфорса
- Уведомления: инфраструктура email + web push

**Результат:** можно зарегистрироваться и войти под любой ролью.

## Этап 1. Школьный учитель (первый запуск)

- Педагог: режим «Школьный учитель», сайдбар режима
- Классы и группы; добавление ученика (приглашение по email, ручное создание, запрос на привязку)
- Расписание: день/неделя/месяц, повторяющиеся занятия, редактирование серии, запрет пересечений, UTC
- Перенос и отмена занятий с подтверждением
- Журнал: оценки 1–5 с комментарием, посещаемость
- Базовая аналитика: посещаемость, средний балл
- Групповой чат класса, объявления, личные чаты по правилу из decisions.md
- Внешняя ссылка на видео (Zoom/Meet) в карточке занятия
- Кабинет ученика: единое расписание, оценки, чаты

**Результат:** учитель ведёт класс на платформе вместо тетради и мессенджера.

## Этап 2. Библиотека, задания, тесты, ДЗ

- Иерархия: предмет → курс → раздел → модуль → задача/теоркарточка
- Материалы: текст с редактором и формулами, видео, PDF, ссылки
- Приватная библиотека педагога; публичная библиотека с очередью модерации
- Прогресс ученика: просмотрено/нет, позиция в видео, избранное
- Типы задач: выбор ответа, текстовый ответ (точное совпадение/regex), развёрнутый ответ (ручная проверка)
- Задачи с кодом на Python: встроенный редактор, песочница (Docker, лимиты времени и памяти), тест-кейсы
- Тесты: порядок заданий, перемешивание вариантов, таймер
- ДЗ: дедлайн, «просрочено», одна отправка, переназначение, история попыток
- Автопроставление оценки из теста в журнал
- КТП: создание с нуля и постепенно, привязка к классу/группе/ученику с датами
- Кабинет модератора: очередь контента (одобрить/отклонить с комментарием)

**Результат:** полный учебный цикл — материалы, ДЗ, проверка, оценки.

## Этап 3. Встроенная видеосвязь

- Видеокомната на LiveKit (или Daily): до 15 учеников + педагог
- Демонстрация экрана, поднятие руки и реакции, чат в занятии
- Автоснижение качества при плохом соединении
- Запись занятий, хранение по правилам тарифа (пока все — бесплатный)
- Лимит 40 минут для бесплатных занятий
- Активный тест на уроке с прогрессом учеников в реальном времени

**Результат:** занятия проходят целиком внутри платформы.

## Этап 4. Маркетплейс и платежи

- Оплата платных занятий (платность задаётся у группы, ученика и занятия — режимов «учитель/репетитор» нет)
- Верификация по 115-ФЗ (паспорт, ИНН, статус самозанятого/ИП, реквизиты) + проверка через API ФНС
- Верификация образования, бейдж
- Публичный профиль, ссылка «Поделиться», онлайн-статус
- Поиск с фильтрами, «Хочу с вами заниматься», открытые заявки, отклики, чат переговоров, «Договорились»
- Компетенции по предметам (справочник модератора)
- Балансы ученика и педагога, двойная запись, атомарные транзакции
- Пополнение через ЮKassa (СБП, SberPay, карта), 100–10 000 ₽
- Escrow: оплата до занятия, автоотмена, окно спора 1 час, выплата за вычетом комиссии
- Политика отмен и штрафов, возвраты на баланс
- Групповые занятия: карточка группы, минимум/максимум, недобор, закрытые группы, 3 неоплаты
- Пробные занятия (платные/бесплатные)
- Вывод средств от 5 000 ₽, автовывод
- Отзывы и рейтинг с модерацией, ответ педагога, оспаривание
- Споры: чат поддержки, решение модератора, логи звонка как доказательства
- Чеки «Мой налог» (или ручная загрузка)
- Отказ педагога от платёжной системы платформы

**Результат:** репетиторы находят учеников и получают оплату через платформу.

## Этап 5. Монетизация и расширения

- Подписка педагога: бесплатный и базовый тарифы, лимиты (3 группы, 40 мин, записи)
- Прокторинг тестов: согласие, сетка экранов, камера по запросу, алерт смены вкладки, запись сессии
- Расширенная аналитика: динамика, сравнение класса, тепловая карта, сводная ведомость, экспорт PDF/Excel
- Интерактивная доска поверх экрана
- КТП на основе чужого шаблона из библиотеки
- Админ-панель целиком: пользователи, финансы, ручные возвраты и выплаты, настройки платформы, аналитика DAU/MAU
- Приоритетная модерация и поддержка для подписчиков
- Яндекс.Метрика

**Результат:** платформа зарабатывает на подписке и комиссии.

## Вне v1

- Родительский аккаунт
- Мобильные приложения
- Бесконечная канва доски
- Языки программирования кроме Python
- Фильтр контактов в чатах

## Стек (согласовано)

- Архитектура: микросервисы
- Брокер: RabbitMQ
- Бэкенд: Python, FastAPI
- Фронтенд: Next.js (TypeScript)
- Видео: LiveKit, self-hosted
- Облако: Яндекс.Облако
- Разработка локально в Docker (docker-compose), потом перенос в облако
